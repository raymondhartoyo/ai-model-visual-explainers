01 / From text and noise to pixels

FLUX.2 [dev] is a 32B-parameter latent rectified-flow transformer for text-to-image generation and multi-reference editing. The 32B figure describes the flow backbone, not the entire pipeline with its separate 24B Mistral text model.

A prompt becomes text features. A seeded Gaussian sample initializes the target latent. Optional reference RGB images pass through the autoencoder’s encoder and become additional image tokens. The transformer repeatedly predicts target-latent changes. Only after sampling finishes does the decoder map the final latent to RGB.

Reference latents are fixed conditioning inputs; the target latent changes at each step. Reference representations inside the transformer are recomputed in standard [dev] editing.

Documented / derived: BFL model card · Sampling implementation

02 / The prompt becomes a sequence of vectors

Optional Mistral prompt upsampling expands the wording before embedding. The reference loader uses Mistral-Small-3.2-24B-Instruct-2506 weights with the compatible Mistral-Small-3.1-24B-Instruct-2503 processor (Mistral/Pixtral and Tekken tokenization). Chat-formatted input is padded/truncated to 512 token positions for embedding.

Returned hidden-state tuple indices 10, 20 and 30 each provide 5,120 values per token. Concatenating them gives 15,360 values. A learned linear projection maps that to the transformer’s width of 6,144. These indices refer to the returned tuple, not human-counted layer numbers.

The embedding pass sets use_cache=False. Optional prompt generation can use an autoregressive language-model cache; that is separate from reference-image KV caching.

Derived: Text encoder · Mistral configuration

03 / Separate streams, shared attention

Image tokens project from 128 to 6,144 values. In each of 8 double-stream blocks, text and image have separate normalization, QKV projections and SiLU-gated feed-forward paths. Q, K and V concatenate along the token axis for joint self-attention. The attention output splits back into text and image paths, each with gated residual updates.

The text and image sequences then merge. Each of 48 single-stream blocks uses a fused input projection for Q/K/V and MLP inputs. Attention and a parallel SiLU-gated MLP reunite through an output projection and gated residual. The MLP ratio is 3.0.

Timestep and guidance embeddings supply modulation (shift, scale and gates). The final layer removes text, normalizes and projects the image sequence back to width 128. In standard editing, the sampler then slices away reference predictions and updates only the target.

Derived: Transformer implementation · Target selection in sampling

04 / What happens inside attention?

Q is a query: what a token is looking for. K is a key: what a token can match. V is a value: the information it contributes. FLUX.2 uses 48 heads with 128 dimensions per head. Q and K receive RMS-based QK normalization, followed by rotary position embeddings (RoPE).

Four position axes (t, h, w, l) each receive 32 RoPE dimensions, with theta 2000. Text varies along l, image tokens along h/w, and different references receive different t coordinates. This position t is distinct from the denoising timestep.

Each head computes softmax(QKᵀ / √128)V: scaled similarity, normalized weights, then a weighted value sum. The heads join and project back to the hidden width. In standard [dev], this is joint self-attention, rather than encoder-decoder cross-attention.

05 / Denoising is a repeated update

Sampling begins at t = 1 and ends at t = 0. The reference schedule shifts timesteps using both image sequence length and step count. The default [dev] settings are 50 steps and guidance 4.0; 28 steps is a documented speed/quality tradeoff. Guidance is embedded in one model pass, rather than requiring the usual separate conditional and unconditional predictions.

At each step the model predicts velocity v. Euler integration applies x_next = x_current + (t_next − t_current) × v. The negative timestep difference matters. The updated latent returns to the same transformer with the next timestep.

The scrubber displays the reference schedule for a derived 1024×1024 example with 4,096 target tokens. Its colored noise-to-structure grid is an educational interpolation, not an actual learned latent, image generation or quality forecast.

Derived / documented: Schedule and Euler loop · Defaults · Model card

06 / Two different reference-image paths

Standard FLUX.2 [dev] includes target and fixed reference tokens in every denoising pass. It recomputes their projections and layer representations. It does not use the dedicated persistent reference-token KV optimization.

FLUX.2 [klein] 9B KV is a specialized model variant. Its first pass processes references and saves per-layer reference K and V. K is stored after QK normalization and RoPE; V is the value projection. Later passes omit reference tokens from the layer inputs and concatenate cached reference K/V inside attention with current text/target K/V.

This fixed bank saves repeated reference processing at a memory cost. It is not an ever-growing autoregressive cache, nor a switch that can simply be enabled on standard [dev]. The [klein] KV path also uses specialized attention masking and fixed reference modulation. The comparison uses [klein]’s four default steps; timings are not benchmarks.

Documented / derived: BFL KV-cache note · Cache implementation · Diffusers pipelines

07 / The latent becomes an RGB image

The autoencoder uses a 32-channel base latent at 8× spatial compression (three downsampling stages). A 2×2 space-to-depth rearrangement packs nearby positions into 128 channels, followed by normalization. The effective spatial compression is 16×.

Derived example, ignoring batch: RGB 3×1024×1024 → base latent 32×128×128 → packed grid 128×64×64 → 4096×128 image tokens. Add 512 text positions for a 4,608-token joint sequence before optional references. This is a worked example, not a fixed resolution requirement.

After sampling, target tokens are scattered back to their grid. Decoding reverses normalization, performs 2×2 depth-to-space to recover the 32-channel base latent, and uses the convolutional decoder to reconstruct RGB. The visualization’s output is a procedural color grid.
