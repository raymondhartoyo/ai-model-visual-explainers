      Read the complete architecture without the diagram
      1. Text becomes embeddings. Images become 14-pixel patches: a nominal 448 × 448 image has 1,024 patches. Patch embedding → 24 vision blocks → post-normalization → 2 × 2 downsampling → merger MLP produces 256 features, each 4,096-dimensional.
      2. Projected features replace image placeholders in the language sequence. Video frames reuse image placeholders inside video boundaries, with image boundaries and timestamps per frame. The processor samples at 2 FPS and uses temporal patch size 2.
      3. The language backbone has 45 layers: 34 KDA and 11 sparse MLA. Zero-based sparse indices are 3, 7, 11, 15, 19, 23, 27, 31, 35, 39 and 43. The last layer is KDA. Layers 0–2 have dense FFNs; all later layers use 8 of 288 routed experts plus one shared expert.
      4. Each attention and FFN sublayer first collapses four mHC streams, then normalizes, computes the sublayer, and expands/mixes the residual streams. Geometry here is conceptual; mHC uses learned mappings and 20 Sinkhorn iterations.
      5. Prefill processes the input sequence, including visual features. Decode adds tokens one at a time. KDA updates bounded recurrent and convolution state. Sparse MLA retains per-token latent KV and indexer state in the reference implementation. IndexPool pools groups of four for candidate scoring, then expands selections to raw indices: up to 2,048 selected positions plus up to three tail tokens.
      6. Output logits support next-token selection. One auxiliary MTP checkpoint layer sits outside the 45-layer backbone. Transformers omits its execution; vLLM can use it for speculative decoding. Cache precision is a serving choice.
