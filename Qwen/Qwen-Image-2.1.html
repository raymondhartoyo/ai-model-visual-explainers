Architecture at a glance

Loading the interactive scene.

Text and optional still images pass through Qwen3-VL 8B. Reference images also pass through a 64-channel VAE. A 32-block, 7B image transformer repeatedly updates a noisy target latent with block-causal attention. Prefix K/V can be reused between steps. The VAE decodes the final latent to RGB or RGBA.

The mechanics, in plain language

    Architecture reference, limits & sources

    Verified versus illustrated. Numbers here come from the released checkpoint and Qwen/Diffusers documentation. Colored cells and animated paths are teaching diagrams, not measured activations or actual generated pixels. A 2048 × 2048 output gives 128 × 128 latent positions because of 16× spatial compression; 16,384 target tokens follows from patch size 1. Text and reference token counts vary with inputs.

    PartReleased detail
    Image DiT32 single-stream blocks; 7B generation component; width 4096; 32 attention heads × 128; MLP ratio 3; 64-channel target; patch size 1; RoPE axes [16, 56, 56].
    Qwen3-VL conditioner36 language layers at width 4096 with 32 query and 8 KV heads. Vision tower: 27 layers, width 1152, 16 heads, 16-pixel patches and 2× spatial merge.
    AttentionText is token-causal. Each image block is internally bidirectional. Later sequence positions can read earlier positions. The target image reads all earlier context and itself.
    KV cacheCondition tokens use timestep-zero modulation; target tokens use the current timestep. Prefix keys and values are stored per DiT layer on the first step and reused on later steps when caching is enabled.
    Image VAE64 latent channels, 16× spatial compression, four-channel input/output for RGBA. Generation uses its decoder; editing also encodes references.
    SamplerFlowMatchEulerDiscreteScheduler with dynamic shifting. Qwen recommends 40 inference steps; default guidance is off.

    Modality scope. This released image pipeline accepts text and still reference images and produces still images. Its Qwen3-VL conditioner has general video-related config fields, but the released QwenImage21Pipeline does not expose a video or audio input/output path. Up to ten image references are documented. Optional Qwen3.5-VL prompt rewrite checkpoints are separate preprocessing tools, not the conditioner shown here.
