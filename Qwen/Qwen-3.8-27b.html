L / 48 layers

Gated DeltaNet · compress into state

Project Q/K/V, z, beta and decay. Apply depthwise causal convolution (kernel 4) to Q/K/V, then SiLU. L2-normalize Q/K and repeat each of 16 Q/K heads across three of the 48 V heads. All heads have dimension 128.

S̄ₜ = exp(gₜ) Sₜ₋₁
Sₜ = S̄ₜ + βₜ kₜ (vₜ − S̄ₜᵀ kₜ)ᵀ
oₜ = Sₜᵀ (qₜ / √128)
yₜ = Wₒ [RMSNorm(oₜ) ⊙ SiLU(zₜ)]

Conceptual per-head recurrence with normalized q and k. β = sigmoid(b); g is a learned negative decay. Prefill can use a chunked computation; single-token decode updates the stored state.

F / 16 layers

Gated full attention · retain K and V

24 query heads share 4 KV heads: six queries per group, with head dimension 256. Q/K RMS normalization precedes partial RoPE; a causal mask prevents access to future tokens.

A = softmax(QKᵀ / √256 + causal mask)V
y = Wₒ [A ⊙ sigmoid(gate)]
Q, gate ← query projection

The output gate is part of the attention sublayer. Language mRoPE assigns temporal / height / width sections [11, 11, 10] across 32 rotary pairs (64 of 256 dimensions). The vision tower uses a separate 2D positional system.

What this walkthrough includes

The main path follows standard Transformers next-token generation. The checkpoint also includes one auxiliary MTP hidden layer (and mtp.* weights); that multi-token prediction module is outside this path. The dense language MLP expands 5,120 → 17,408 → 5,120. The configured native context length is 262,144 positions; the model card describes extension up to 1,000,000 tokens.
