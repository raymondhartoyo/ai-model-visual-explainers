What happens to an image input?

Nothing inside this checkpoint: the open-weight Qwen3.8-2.4T-A95B is text-only. Its model card classifies it as a causal language model and the pinned config names Qwen3_5MoeForCausalLM. There is no image processor, vision encoder, or visual-token bridge to draw. Images must first be converted to text by a separate model or system.

D / 69 layers

Gated DeltaNet · summarize history

Sixteen Q/K heads and 128 V heads use dimension 128. Q, K and V first pass through a depthwise causal convolution with kernel 4. A learned decay and update gate then fold the sequence into a recurrent state.

conv state: [B, 20,480, 4]
recurrent state: [B, 128, 128, 128]

Sₜ ← decayₜ · Sₜ₋₁ + gated correction
oₜ ← Sₜᵀqₜ

During cached decoding, both state shapes stay fixed as the next token updates them in place.

F / 23 layers

Gated full attention · retain K and V

Sixty-four query heads share four KV heads, so each KV head serves 16 query heads. All heads are 256-wide. Q and K receive RMS normalization; RoPE rotates 64 of their 256 dimensions.

A = softmax(QKᵀ / √256 + causal mask)V
y = Wₒ[A ⊙ sigmoid(gate)]

K, V each: [B, 4, T, 256]

The sigmoid output gate modulates the attention result before the output projection. Full-attention cache storage grows with sequence length T.

A fresh expert choice in every layer

The bank shown in 3D belongs to the currently selected layer.

Sparse feed-forward path

10 routed + 1 shared

After the layer's second RMSNorm, a router scores 512 SwiGLU experts. Only the top 10 routed experts run for that token. Their weighted outputs combine with one always-computed shared expert through a learned sigmoid gate.

scores = softmax(router(x))
routed = Σᵢ∈top10 scoresᵢ · Expertᵢ(x)
output = routed + sigmoid(shared_gate(x)) · SharedExpert(x)

expert intermediate width: 2,048
Why 2.4T can activate 95B

Weights are large; the path is sparse

The 512 expert sets are stored at every decoder layer, which drives the total parameter count. A token touches a small subset in each layer, so its active parameter path is much smaller than the complete checkpoint.

How literally should you read the diagram?

The layer counts, ordering, head counts, dimensions, expert counts, vocabulary, native context, and cache shapes come from the pinned model configuration and Transformers implementation. Block size, spacing, token route, and the highlighted expert identities are explanatory schematics. The model may choose different experts for every token at every layer.

The config also records one auxiliary multi-token-prediction (MTP) hidden layer used by the checkpoint's MTP mechanism. It sits outside the 92-layer main decoder and outside this ordinary one-next-token-at-a-time walkthrough.
