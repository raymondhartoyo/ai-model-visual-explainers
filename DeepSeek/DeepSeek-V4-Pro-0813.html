How to read this model

Dimensions come from the exact 0813 checkpoint. Mechanisms come from DeepSeek’s V4 report and reference implementation; the release card confirms the shared architecture. The report describes Pro as approximately 1.6T total parameters and 49B activated per token. The checkpoint page’s automated 1.7T count is a different accounting figure.

All token choices, expert selections, geometry, and motion here are teaching illustrations. No weights are loaded and no inference runs. Cache counts describe logical completed entries, not allocated GPU memory or latency.
