Read the diagram correctly

Geometry, animated paths, attention scores, expert choices and example tokens are teaching illustrations. This page loads no model weights and performs no inference. Counts refer to the named checkpoint; dimensions are not drawn to scale.

Layers are numbered 1–40 here. Source code uses 0–39. The separate 32-layer vision encoder and three DSpark draft blocks are outside the 40-layer language backbone. Engram contributes a separate 196B conditional-memory parameters.
